# The Farmer's Descent

A 2D boss-fight bullet hell game built by Team_Platformers at DigiPen (AY2025/T1).

This was made as an academic project for DigiPen's AY2025/T1 term.

## Download & Play

1. Click the green **Code** button on this repo, then select **Download ZIP**.
   - Total size is ~18.7MB, so it may take a moment to download.
2. Once downloaded, extract the ZIP file.
3. Open the extracted folder and navigate to `Release-x64`.
4. Run `setup.exe`.
5. Windows Defender may show a warning that this is an unrecognized app. Click **More info**, then **Run anyway** to launch and play.

## Controls

Controls are displayed in the top-right of the screen after DigiPen and the game's splash screen.
